# Backlog

**Future ideas and features** that are out of scope for Version 1 but will be considered for Version 2+.

---

## The Rule (June 26, 2026)

> Nothing gets added to the repository without belonging to a milestone.

Any new idea — TikTok support, A/B testing, multi-language, anything — goes here first. It does not interrupt the current milestone. It does not get a branch, a folder, or a line of code until it's been promoted from this backlog into an actual milestone (M9+ or a V2 milestone series).

This is the rule that keeps Brainrot a finishable product instead of an ever-expanding pile of half-built features.
