## What We're Building

Not a video generator. An **AI Content Operating System** — a small media company where every team member (researcher, writer, editor, producer, publisher, analyst) is an AI agent, and the founder is the creative director.

## The Core Insight

Everyone is competing on "who can generate a better video." Almost nobody is competing on "who decides which video to make." That decision layer — research, ranking, learning — is Brainrot's moat. Video rendering is a commodity we buy, not build (see Decision #6, #12).

## What Success Looks Like (V1)

One YouTube Shorts channel + one Instagram account, fully automated end to end:
research → rank → script → approve → produce → publish → measure → learn.

See `docs/00-roadmap.md` for the full V1 success criteria.

## What Success Looks Like (V2+)

Multiple channels, multiple niches, a CEO AI that runs the whole operation conversationally — but only after V1 proves the core loop works with real audience data. See `BACKLOG.md`.

## Non-Negotiable Principles

1. Automation replaces repetition, not judgment. If it needs judgment, the founder does it.
2. Every external provider (video, voice, AI model) must be replaceable — see Decision #6.
3. Quality compounds, spam doesn't. Mode A (human approval) before any autonomous publishing.
4. Nothing gets added to the repo without belonging to a milestone — see CONTRIBUTING.md.
