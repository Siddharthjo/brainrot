# Brainrot Studio — Page Specifications

Per Decision #18, every Studio page gets designed using the same 8-question framework before being built in Lovable. Each page's spec lives here, one file per page, numbered in build order.

## Workflow Per Page

1. Why does this page exist?
2. What can the user do?
3. What information is displayed?
4. What settings exist?
5. What backend does it require?
6. External integrations?
7. Database tables?
8. Lovable prompt (only written once 1–7 are frozen)

**"Frozen" = frozen enough to build V1.** Not a perfect final design — sufficient to move to the next page. Extension points (presets-as-rows, sources-as-typed-rows, generation-output-in-future-schema-shape) are mandatory on every page per Decision #18, so Phases 8–12 plug in later without a redesign.
