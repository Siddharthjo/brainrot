# branding/

**Brainrot's own brand assets only. Not a media library.**

Brainrot doesn't own or store content media — generated videos, voiceovers, and B-roll live with the production provider and Cloudflare R2 (see Decision #8). This folder is exclusively for assets belonging to the Brainrot product/dashboard itself and to the channel brands it manages.

## Subfolders

- **`logos/`** — Brainrot logo + per-channel logos (Story Vault, NeuroVault, Founder Blueprint, Overfitting AI)
- **`icons/`** — UI icons used in the dashboard
- **`ui/`** — Static UI assets (illustrations, backgrounds) used by the frontend

## Rule

If it's generated content (a video, a thumbnail, a voiceover) — it does **not** belong here. It belongs in R2, referenced by the database. This folder is brand identity only.

**Status:** Empty until M2 (Foundation) when channel branding is defined.
